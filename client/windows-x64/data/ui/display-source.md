# Cinzel

Cinzel Bold, distribuída sem modificações como `display.ttf`. É a face de
exibição: marca, títulos e cabeçalhos. O corpo do texto continua em `font.ttf`.

- Projeto: https://github.com/NDISCOVER/Cinzel
- Arquivo: https://github.com/NDISCOVER/Cinzel/blob/master/fonts/ttf/Cinzel-Bold.ttf
- Licença: SIL Open Font License 1.1, incluída em `display-license.md`.

Capitais romanas inscricionais, versão 2.000, com Latin-1 completo (inclui
ã õ ç á é í ó ú â ê ô à). A fonte acompanha o aplicativo; não requer
instalação no sistema.
